# Tarot card pictures

One picture per card, 1024 x 1536 webp, named by the card's id (see docs/tarot.md): `00-fool.webp` ... `21-world.webp`, and `<suit>-<rank>.webp` for the minor cards (`wands-ace.webp` ... `pentacles-king.webp`).

Not yet drawn: `01-magician` and `wands-seven`. A card without a picture is drawn from its symbol, so nothing breaks; add the file with that name and it appears.
`back.webp` (the back of the cards) is not here either.

The major cards are also here under the older names the page used before the deck grew to 78 cards (`00-the-fool.webp`, `01-the-magician`, `16-the-tower.webp` ...; where the older name is the same as the id there is only one file), so the page that is live today shows them. Once the 78-card page is live (it reads the ids above) those older names can be deleted.
